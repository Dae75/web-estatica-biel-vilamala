## Què és Hugo?

**Hugo** és un generador de webs estàtiques de codi obert, escrit en el llenguatge Go. Tu escrius el contingut en fitxers de text (Markdown) i Hugo el combina amb unes plantilles per generar una web completa en HTML, CSS i JavaScript, llesta per publicar.

## Com funciona

1. **Escrius** el contingut en fitxers `.md` dins la carpeta `content/`.
2. **Defineixes** l'aspecte amb plantilles (`layouts/`) i estils (`static/css/`).
3. **Hugo construeix** la web i la deixa a la carpeta `public/`.
4. **Publiques** els fitxers a GitHub Pages, Netlify o qualsevol hostatge.

## Quan té sentit usar-lo

- Webs corporatives, portafolis, blogs i documentació tècnica.
- Projectes on la velocitat de càrrega i la seguretat són importants.
- Quan vols control total del codi i versionar-ho tot amb Git.

No és la millor opció per a webs amb comptes d'usuari, comentaris propis o botigues complexes, perquè una web estàtica no té servidor ni base de dades. Tot i això, es poden afegir serveis externs per cobrir aquestes necessitats.
